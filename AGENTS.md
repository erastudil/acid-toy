# acid-toy

GPL jam. not a product. coding music.

**why:** long hard acid mixes. darkest / hardest.

**what:** genre pack = DNA + families + rules. combinator emits legal tracks. renderer plays them.

**how:** python SoT. textual TUI. sounddevice. synthesized drums. 303 ladder in-process. milkdrop-class GL viz.

the LLM does not write notes.

## law

- pack is the law. hard rules reject. soft rules score.
- one IR. json on disk. player consumes it.
- no roland dumps. synthesize drums.
- no sample theft. no commercial loops.
- colors: black · white · ina violet `#8b5cf6` · Cascadia.
- no essays on the glass. tooltips.
- later packs share the IR. combinator does not change.
- splittercore and above are out. noise, not music.

## ear

query `hard acid techno` is the genre. donit mixes are the reference ear: modern, 150+, toxic, industrial, screaming 303. stay-up-forever is the ancestor, not the ceiling.

vibe: mescaline and cybercrime. nuclear waste toxic acid death. hype on the rolls.

## later packs (not v1)

psytrance · vaporwave · chillwave · hardstyle · uk hard dance · happy hardcore · uk hardcore · jp speedcore. stop before splittercore.

## run

```
python -m acidtoy
launch.cmd
```

space play · n skip · v viz · esc close viz · 1-5 preset · [ ] vol · q quit

centered player. `v` opens a GL milkdrop window (feedback warp + waveform). not a terminal shader.

kick: dry sub. never tanh the sub. never peak-normalize the mix against the 303. 303 screams above the floor.
